# Career track — full stack with a Python backend

Intended positioning: junior software developer who connects a typed React UI to
a Python API and relational database, then grows into data-rich and AI-assisted
applications. Frontend breadth adds relevant job titles; this is not evidence
that this track has more suitable junior vacancies than backend alone.

## Search terms

- Junior Full Stack Developer / Junior Fullstack Entwickler Python React
- Junior Software Developer Python Web Applications
- Junior Python Developer / Junior Backend Developer
- Research Software Engineer / Forschungssoftware Webanwendungen
- Junior Data Engineer where the role includes APIs and data applications

Search Germany first, then neighbouring countries. Exclude internships, working
student posts and enrolment requirements. Include graduate roles and suitable
salaried research/PhD roles. Check language requirements individually: the
confirmed profile says B1 certified, B2 in preparation.

## Vacancy screening

For an application shortlist, verify:
1. Employer or employer-hosted ATS still lists the role.
2. Original publication is within 72 hours, not a refreshed aggregator date.
3. Junior scope or requirements the candidate can demonstrate.
4. Location, language and application route are clear.

Unknown original dates remain unknown; do not call them fresh. Applicant counts,
competition and hidden hiring needs must never be guessed.

## Parallel routine

Suggested effort: 60–90 minutes of project work, 30 minutes reviewing one or two
employer-verified vacancies, and 15 minutes practising an explanation.
Apply while building. Use recurring requirements to choose small project tasks.

Do not claim this scaffold as independently developed candidate work. Describe
the candidate's implemented changes, tests and explanations after they happen.
